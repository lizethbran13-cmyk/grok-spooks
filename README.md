# Grok Spooks

A cute-spooky 3D co-op ghost-hunting puzzle game in the style of Luigi's Mansion 3, made for phones and desktop.

- Explore Grok Manor: 6 haunted areas (Grand Foyer, Library, Haunted Kitchen, Greenhouse, Museum & Crypt, Clock Tower), 35 rooms, 6 boss ghosts
- FLASH to stun ghosts, hold the Grok-Vac to suck them in (tug-of-war + SLAM!), BLOW, PLUNGER and DARK-LIGHT
- 13 kinds of paranormal pests, each with its own trick
- Co-op puzzles (plates, levers, mirrors, paintings, hidden switches, fans, crates) - solo players use a green Goo clone
- Coins and gems buy upgrades; hidden gems and Boos in every area
- Online co-op for 2-3 players with a 5-letter room code (or start from the Grok Arcade lobby)

Play: https://lizethbran13-cmyk.github.io/grok-spooks/
